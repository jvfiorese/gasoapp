# Gasoapp

Apoio à leitura de gasometria arterial no intraoperatório: identifica os distúrbios (abordagem tradicional de Berend, NEJM 2014, e Stewart em aba extra), lista hipóteses ordenadas pelo contexto e mostra condutas imediatas com doses e fontes.

- App: abra o link do GitHub Pages no Safari do iPhone → Compartilhar → Adicionar à Tela de Início. Funciona offline.
- Tudo roda no aparelho; nenhum dado é enviado.
- Código-fonte em `fonte/` (`python3 fonte/build.py`, testes em `node fonte/testes/casos.test.js`, `node fonte/testes/auditoria.test.js` e `sh fonte/testes/referencia/rodar.sh`).

Ferramenta de apoio à decisão. Não substitui o julgamento clínico.
